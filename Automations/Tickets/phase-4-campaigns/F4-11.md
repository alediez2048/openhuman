# F4-11 Primer: `/campaigns` List Route

**Project:** OpenHuman — Workflows & Automations / Phase 4 Campaigns
**Dependencies:** F4-3 (RPC surface).

---

## What Is This Ticket?

A new top-level route in the React app: `/campaigns`. Lists every campaign (active, paused, drafts) as cards. Replaces `/workflows` as the primary user surface — `/workflows` becomes an admin/debug view.

### Why It Matters

In Shape β, campaigns are the unit of user organization. Workflows are implementation detail. The list view is the user's "home" — where they land after onboarding, where they go to check on their automations.

---

## Goal

`app/src/pages/Campaigns/CampaignsList.tsx` — the route component.

Layout:
- Header: "Campaigns" + "+ New Campaign" button (opens chat preloaded with "Help me create a campaign").
- Filter chips: All / Active / Paused / Draft / Archived.
- Card grid (one card per campaign):
    - Title (campaign name).
    - Subtitle: trigger summary ("Daily 9am" / "Webhook + Schedule") OR throttle ("20/day").
    - Status pill: Active / Paused / Draft / Wound-down / Archived.
    - Progress: "12/30 days · 240/600 sent · 18 replies" (campaign-level metrics).
    - Entity binding: small badge with adapter icon ("Attio: People" / "Sheets: vendor-outreach").
    - Overflow menu: Pause, Resume, Archive, View detail, Delete.
- Empty state: friendly explainer + "Create your first campaign" CTA opens chat.

Bottom-tab integration:
- New tab "Campaigns" in `BottomTabBar.tsx` (replaces "Workflows" tab; workflows becomes a sub-route or admin view).
- Default landing after sign-in: `/campaigns`.

Routing changes in `AppRoutes.tsx`:
- Add `/campaigns` → `CampaignsList`.
- `/campaigns/:id` → `CampaignDetail` (F4-12).
- `/workflows` stays but moves to a debug/admin section (deep link only, not in bottom-tab).

RPC integration:
- `coreRpcClient.campaigns_list(filter)` on mount.
- Re-fetch on `DomainEvent::Campaign*` via the existing socket bridge.
- Optimistic UI on overflow actions (Pause/Resume/Archive).

State management:
- New Redux slice `campaigns` (mirrors existing `workflows` slice if there is one, else fresh).
- Selectors: `selectAllCampaigns`, `selectActiveCampaigns`, etc.
