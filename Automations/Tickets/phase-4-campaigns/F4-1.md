# F4-1 Primer: Campaign Type + Lifecycle

**Project:** OpenHuman — Workflows & Automations / Phase 4 Campaigns
**Dependencies:** Phase 2 shipped. None within Phase 4.

---

## What Is This Ticket?

The type foundation for the Campaign abstraction. Lands the `Campaign` struct, its lifecycle states, and supporting types (`Throttle`, `ApprovalPolicy`, `EntityRef`, `OutcomeSpec`) under a new domain `src/openhuman/campaigns/`.

### Why It Matters

Every downstream ticket (F4-2 store, F4-3 RPC, F4-10 drafter, all UI) consumes these types. The type universe must be locked first so parallel work doesn't drift.

---

## Goal

```rust
// src/openhuman/campaigns/types.rs
pub type CampaignId = String; // UUIDv4

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub struct Campaign {
    pub id: CampaignId,
    pub schema_version: u32,
    pub name: String,
    pub description: Option<String>,
    pub status: CampaignStatus,
    pub entity_binding: EntityRef,
    pub throttle: Option<Throttle>,
    pub approval_policy: ApprovalPolicy,
    pub target_outcome: Option<OutcomeSpec>,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
    pub last_run_at: Option<DateTime<Utc>>,
}

#[serde(tag = "type", rename_all = "snake_case")]
pub enum CampaignStatus { Draft, Active, Paused, WoundDown, Archived }

#[serde(tag = "type", rename_all = "snake_case")]
pub enum EntityRef {
    GoogleSheet { spreadsheet_id: String, range: String },
    Attio { workspace_id: String, object_type: String }, // "people" | "companies" | "deals"
    // future: Airtable, Notion, NativeSqlite
}

pub struct Throttle { pub max_per_window: u32, pub window: ThrottleWindow }
pub enum ThrottleWindow { PerDay, PerHour, PerMinute }

#[serde(tag = "kind", rename_all = "snake_case")]
pub enum ApprovalPolicy {
    AutoReply,    // Mode (A) — Phase 4+
    DraftAndApprove, // Mode (B) — Phase 4 MVP
    Triage,       // Mode (C) — Phase 4+
    Tiered { rules: Vec<TierRule> }, // Mode (D) — Phase 5+
}

pub struct OutcomeSpec { pub metric: String, pub target: f64, pub deadline: Option<DateTime<Utc>> }
```

`Workflow` gains: `pub campaign_id: Option<CampaignId>` (default `None`; soft FK enforced in F4-2's migration).

### Deliverables

- [ ] `src/openhuman/campaigns/mod.rs` + `types.rs` with the full type universe.
- [ ] `Workflow.campaign_id: Option<CampaignId>` field (additive, `#[serde(default)]` for backwards compat).
- [ ] Round-trip Serde tests in `types_tests.rs` for each variant of every enum.
- [ ] Documentation: rustdoc on `Campaign`, `CampaignStatus` transitions, `EntityRef` variants.

### Tests

- Every enum variant round-trips through JSON.
- `Workflow` with `campaign_id: None` and `campaign_id: Some(...)` both deserialise.
- `Throttle` validation: `max_per_window > 0`.
- `ApprovalPolicy::Tiered { rules: vec![] }` is structurally valid (empty tier list = fall back to last default).
