# F4-4 Primer: EntityStore Trait + Adapter Registry

**Project:** OpenHuman — Workflows & Automations / Phase 4 Campaigns
**Dependencies:** F4-1 (`EntityRef` type).

---

## What Is This Ticket?

The pluggable backbone for Campaign entity bindings. Defines the `EntityStore` trait, the adapter registry, the schema-discovery surface, and the identity model. F4-5 and F4-6 land the first two adapters against this trait.

### Why It Matters

Per the 2026-05-26 grill (Option 3), every campaign has an `entity_binding: EntityRef` that points at an external structured store (Sheets, Attio, eventually native). The trait is the contract every adapter satisfies. Getting this right means future adapters cost a single ticket each; getting it wrong means migrating every campaign when the leaky abstraction shows.

## Goal

```rust
// src/openhuman/campaigns/entity_store/mod.rs
#[async_trait]
pub trait EntityStore: Send + Sync {
    /// Stable identifier for this adapter ("google_sheets", "attio", "native").
    fn adapter_id(&self) -> &'static str;

    /// Schema discovery — returns the user-visible field shape.
    /// `Sheets` derives from column headers; `Attio` returns the typed object schema.
    async fn schema(&self) -> Result<EntitySchema>;

    /// Query records. `EntityQuery` supports filter-by-field-equality + limit + offset.
    /// Advanced query semantics (sort, range filters) deferred to follow-up.
    async fn list(&self, query: EntityQuery) -> Result<Vec<EntityRecord>>;

    /// Fetch a single record by id.
    async fn get(&self, id: &EntityId) -> Result<Option<EntityRecord>>;

    /// Patch a record. Field-level merge, not whole-row replace.
    /// Atomicity contract: caller MUST treat success as "this write committed,
    /// readers will see it." Adapters that can't guarantee this fail fast.
    async fn update(&self, id: &EntityId, patch: EntityPatch) -> Result<()>;

    /// Inbound subscription for triggering workflows on entity changes.
    /// Adapters that don't support real-time push (Sheets) return a polling
    /// stream; adapters with webhooks (Attio) return event-driven.
    /// `None` means subscription isn't supported (read-only adapter).
    async fn subscribe(&self) -> Result<Option<EntityChangeStream>>;
}

pub struct EntitySchema {
    pub fields: Vec<EntityFieldSchema>,
    pub primary_field: String, // e.g., "email" for Sheets, "record_id" for Attio
}

pub struct EntityFieldSchema {
    pub key: String,
    pub label: String,
    pub kind: EntityFieldKind,
    pub required: bool,
}

#[serde(tag = "kind", rename_all = "snake_case")]
pub enum EntityFieldKind {
    String,
    Number,
    Bool,
    Enum { variants: Vec<String> },
    DateTime,
    EmailAddress,
    PhoneNumber,
    Url,
    Unknown,  // fallback for Sheets columns whose type we can't infer
}

pub struct EntityQuery {
    pub filters: Vec<EntityFilter>,
    pub limit: Option<u32>,
    pub offset: Option<u32>,
}

pub struct EntityFilter {
    pub field: String,
    pub op: EntityFilterOp,
    pub value: serde_json::Value,
}

pub enum EntityFilterOp { Eq, NotEq, Contains, IsNull, IsNotNull }

pub struct EntityRecord {
    pub id: EntityId,
    pub fields: serde_json::Map<String, serde_json::Value>,
    pub updated_at: Option<DateTime<Utc>>,
}

// Composite: (adapter_id, native_id) — stable across schema changes within an adapter.
pub struct EntityId {
    pub adapter: String,
    pub native: String,
}

pub struct EntityPatch {
    pub fields: serde_json::Map<String, serde_json::Value>,
}

pub type EntityChangeStream = Pin<Box<dyn Stream<Item = EntityChange> + Send>>;

pub struct EntityChange {
    pub id: EntityId,
    pub kind: EntityChangeKind,
    pub at: DateTime<Utc>,
}

pub enum EntityChangeKind { Created, Updated { fields: Vec<String> }, Deleted }
```

Adapter registry (`src/openhuman/campaigns/entity_store/registry.rs`):

```rust
pub fn open_entity_store(
    config: &Config,
    binding: &EntityRef,
) -> Result<Box<dyn EntityStore>> {
    match binding {
        EntityRef::GoogleSheet { .. } => GoogleSheetsAdapter::open(config, binding),
        EntityRef::Attio { .. }       => AttioAdapter::open(config, binding),
    }
}
```
